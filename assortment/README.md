# 便民欢线上选品与采购供应商核对

静态网页入口：`index.html`。页面可在普通浏览器中使用，费用和售价修改保存于访问者自己的浏览器，不会修改其他人的数据。

分析日期：2026-11-07。来自采购参考表的4536条记录，商城72个条件候选、直播30个条件候选，去重合计74品。候选尚需采购核价、库存、实物规格与履约共同放行。

商品旁显示原表供应商或采购渠道。原表未给具体商家的，明确标记待采购确认。同品牌其他规格的商家只作为询价线索，不确认供应本SKU，不继承其价格或成本。

下载文件：

- `便民欢-商城选品与直播30品.xlsx`：初始利润试算模型。
- `便民欢-采购供应商对照表.xlsx`：74个候选、原供应渠道、4条同品牌询价线索，以及空白采购确认栏。

本目录单独维护，不改变父目录的既有商城演示页面。静态网页不连接实时库存或订单系统。
